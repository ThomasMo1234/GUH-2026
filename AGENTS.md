# Instructions for AI agents working on this repo

1. **Read `DEVLOG.md` first**: current state, decisions, next tasks.
2. Run and test your changes (use `MOCK_AI=1` for the backend if no API keys). Say plainly what you did not test.
3. Before you finish, append an entry to the Log in `DEVLOG.md` and update "Current state" and "Next tasks".
4. Stay within hackathon scope: in-memory state, no database, no accounts. Keep simulated students labelled in the UI.
5. Setup and run commands are in `README.md`.
